# 整车热管理岗位能力映射与面试表达

本文把项目能力映射到整车厂、一级供应商常见的新能源整车热管理岗位。所有数字以 `final-reviewed-formal-v2`、四个suite manifest和 `results/logs/upgrade_manifest.json` 为准；合成数据结论只用于方法验证，不包装成实车标定结果。

## 1. 岗位能力—项目证据映射

| 岗位能力 | 本项目完成内容 | 可核验代码/结果 | 面试时应强调的工程判断 |
|---|---|---|---|
| 整车热系统建模 | 纵向动力、电池双节点、电驱、座舱2R2C、热泵/PTC、换热器与能量账本耦合 | `src/ev_thermal`、`results/tables/strategy_comparison.csv` | 先闭合电与热的能量路径，再谈控制收益 |
| 一维液压与部件匹配 | 泵曲线和命名部件压降闭合工作点，覆盖三种液路拓扑和泵/散热器规格扫描 | `src/ev_thermal/components/network.py`、`results/architecture` | 流量不是常量；拓扑结论要受可行域、成本和布置约束 |

## 2. 可用于简历的项目描述

- 搭建纯电动汽车整车集成热管理仿真平台，耦合电池、电驱、座舱、热泵/PTC及一维液压网络，以电/热账本审计多工况守恒，正式六工况液压求解失败为0。
- 建立电池热参数受界辨识与未参与拟合的合成holdout验证流程；合成真值恢复中三参数Jacobian满秩、条件数6.44，温度RMSE由0.414 °C降至0.023 °C，同时明确该结果不等同于实车标定。
- 对独立双回路、液液耦合双回路和共享热汇三种架构开展18组工况比较及45个部件规格点扫描，识别9个流量包络不可行点并形成带适用边界的架构推荐。
- 构建到站预热—快充—相对老化联合优化，评估186个可行候选并提取33个工程分辨率Pareto代表点；低温推荐点将充电时间控制为22.75 min、预热能量1.80 kWh，并通过环境、到站时间和站端降额鲁棒性检查。
- 建立可解释的LSTM预测增强策略和确定性回退机制；六工况平均电池峰值降低0.312 °C、百公里电耗增加0.097 kWh/100km，量化安全裕度与附件能耗的权衡。

## 3. 两分钟项目介绍

我的项目不是单独做一个电池温控器，而是把动力、热源、液路、制冷制热和充电连接成一个可审计的整车系统。第一层是物理模型：从轮端功率追踪电池和电驱损耗，用热容网络描述部件温度，用泵曲线与各部件压降求真实工作点，并用电、热账本检查能量闭合。第二层是标定和验证：我建立了参数注册、受界辨识、holdout验证及灵敏度分析；目前用合成隐藏真值证明方法正确，但不会把它说成实车标定。第三层是控制与优化：LSTM只预测未来热负荷并有限修正规则阈值，异常时确定性回退。围绕快充，我又把到站预热、SOC、充电功率接受和相对老化串起来，对预热时机、目标温度和功率做Pareto优化。最终我能解释的不只是“温度降了多少”，还包括为什么会降、消耗了多少能量、是否满足部件和功率约束，以及结论在什么条件下成立。

## 4. 高频追问与回答抓手

1. **为什么不能直接给定冷却液流量？** 泵工作点由泵扬程与网络压降交点决定，阀门、温度物性和拓扑变化都会改变流量；固定流量会掩盖泵选型不足与局部阻力影响。
2. **为什么共享热汇排名第一仍不能直接定型？** 当前只比较热性能和能耗名次，尚缺成本、空间、NVH、泄漏风险、故障隔离和供应商性能图；它是模型假设下的候选，不是量产定案。
3. **参数辨识怎样避免过拟合？** 训练与holdout episode分离，参数有物理上下界，同时检查残差、Jacobian秩、条件数和是否触边；获得实测数据后还需跨温度、流量和老化状态验证。
4. **预热为什么可能增加老化？** 升温能降低低温充电阻抗和时间，但更高温度也会加快温度敏感的副反应；因此使用相对damage做策略比较，而不声称预测绝对寿命。
5. **为什么温度不直接作为第四个加权目标？** 温度已经通过目标温度决策、到站与峰值约束进入问题；原始单位直接加权会造成量纲支配。最终对时间、能量、相对老化做归一化选择，并保留整个Pareto前沿供标定决策。
6. **AI预测错了怎么办？** 历史不足、输出非有限、维度错误或超工程范围时回退基准控制；无效预测注入测试中温度与能量偏差均为0。

## 5. 结论边界

- 当前所有部件默认参数用于系统方法验证；车型开发必须接入供应商泵、压缩机、换热器和电芯性能图后重新标定。
- 老化模型只支持同一模型假设下的相对策略比较，不能报告绝对寿命或质保里程。
- 架构排序未纳入成本、布置、可靠性、NVH和制造约束。
- LSTM训练数据主要来自仿真，必须经过台架/实车域适配和覆盖度验证后才可上车。
