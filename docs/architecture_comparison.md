# 一维液路网络与架构选型

## 从固定阻力到部件压降闭合

整车主路径不再直接调用 `Pump.working_point(..., 360000/260000)`。电池与电驱回路分别由命名部件组成：供回水管、局部阻力、冷板或电机/逆变器水套、散热器芯体和路由阀。每个时间步先按当前冷却液物性计算各部件压降，再求解：

```text
DeltaP_pump(n, m_dot) - sum_i DeltaP_i(m_dot, rho, mu, valve_i) = 0
```

泵曲线使用相似定律，管路使用 Darcy-Weisbach，局部部件使用可追溯的二次阻力。求解结果输出部件 pressure budget、泵压升、质量流量、效率、电功率、闭合残差和状态。零泵速返回物理零流量；关闭阀、非法损失、无交点和数值失败都有不同诊断。短暂失败最多复用两步上一次可行解，连续失败终止该架构仿真，不通过裁剪制造伪可行流量。

冷板、散热器和液液换热器的单程出口温度由 `m_dot*cp*(T_out-T_in)=Q` 给出；整车采用“部件热流 + 混合容积储能”离散，储能节点只积分一次，避免同时用出口温度推进又重复加入同一热量。

## 三种拓扑

1. **独立双回路**：电池和电驱各有泵与散热路径，耦合最弱、故障隔离最好，是 reference architecture。
2. **液液换热耦合双回路**：保留两套液压回路，在两回路之间增加 epsilon-NTU 液液换热器。热量受两侧流量、UA 和入口温差共同限制，在两个冷却液账本中大小相等、符号相反。
3. **多通阀共享热汇**：两条支路保持各自泵和被冷却部件，通过共享散热器热汇混合排热；共享风扇功只计一次，散热量按支路焓差潜力分配。

## 选型指标

六类相同工况分别运行三种架构，比较电池/电机峰值温度、泵与附件能耗、最大压降、平均流量、液液换热量、守恒误差和求解失败数。部件规格扫描改变泵相似尺度与散热器 UA，除温度安全外还检查电池与电驱最大流量包络；不可行点保留明确原因。

`architecture_ranking.csv` 使用每个工况内的等权名次和，不把摄氏度、kWh 等原始量纲直接相加。它只给出当前参数与约束下的工程推荐，不替代成本、布置、NVH、可靠性和供应商能力评审。
