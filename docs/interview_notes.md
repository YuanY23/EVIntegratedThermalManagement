# 答辩与面试说明要点

1. **为什么不用CFD？** 本研究目标是整车能量流与控制策略比较，需要大量跨工况动态计算。集总参数模型计算快、能量路径清楚；冷板局部参数可以由CFD或试验标定后回填。
2. **占空比为什么不能直接等于流量？** 实际流量由泵扬程曲线和系统阻力曲线交点决定，冷却液黏度、管路压降和泵转速都会改变工作点。
3. **冷板换热为什么随流量非线性？** 流量改变Re和Nu，进而改变对流换热系数与UA；同时流体热容量率和压降也变化。
4. **如何保证能量守恒？** 每步记录电池端功率、电驱DC功率、附件功率及残差；热节点按进入热量减离开热量积分。结果报告归一化能量残差。
5. **热泵模型为什么是准稳态？** 整车研究关注COP、能力和环境温度影响，缺少制冷剂回路详细标定时，建立完整两相瞬态模型反而引入无法验证的参数。
6. **AI做了什么？** LSTM只预测未来300秒三类热负荷。预测结果有限幅度调整规则控制的阈值和启用时机，执行器仍由状态机和PID控制。
7. **如何防止数据泄漏？** 先按完整episode划分训练、验证和测试，再在各自episode内切窗口；标准化器只拟合训练集。
8. **预测失效怎么办？** 历史不足、维度错误、非有限值或超出工程范围时均返回无效状态，预测层不修改任何基准阈值。
9. **模型如何标定？** 电池内阻/热容来自脉冲与热响应试验，电驱效率来自台架图，泵和换热器来自性能试验，座舱UA由浸车与热平衡试验辨识。
10. **项目局限是什么？** 参数不是特定车型实测标定值；未建立三维温度均匀性、制冷剂两相瞬态和部件老化。结论适用于方法与趋势，不替代实车验证。
