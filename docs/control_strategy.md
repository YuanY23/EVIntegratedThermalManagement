# 热管理控制策略

## 基准策略

上层状态机负责待机、电池低温加热、座舱制热、余热回收、一般冷却、强化冷却和座舱制冷。模式切换使用温度滞环，防止临界点频繁切换。局部PID根据电池、电机、逆变器和座舱温度偏差形成连续需求，经限幅和抗积分饱和后转换为泵、风扇、压缩机、PTC和阀门命令。

控制约束包括：执行器命令限制在0到1；强化冷却优先保护电池；电池低温时优先预热；只有电驱余热高于门槛且座舱需要制热时才打开余热阀；无热需求时保留小流量防止局部热积聚。

控制器允许并行热任务。例如电池预热时仍可由热泵和独立座舱PTC供热；电池提前冷却时，座舱制热/制冷请求不会因模式切换而丢失。电池chiller和座舱HVAC共享压缩机能力，PID内部状态在预测阈值变化时保持连续。泵、风扇、压缩机、chiller和PTC均通过一阶惯性环节形成实际响应，避免5 s采样下的非物理瞬时跳变。

## 预测增强策略

LSTM输出未来300秒电池产热、电驱余热和座舱净负荷。预测层只计算峰值、均值和可信状态，再进行三类调整：

1. 未来电池产热峰值较高时，有限幅度降低冷却启用温度，提前建立流量；
2. 未来座舱制热负荷较高且电驱余热充足时，降低余热回收启用门槛；
3. 预测不可用、预热历史不足、出现非有限值或超出工程范围时，阈值恢复为基准值。

预测值不进入泵、风扇或压缩机占空比接口。因此即使模型误差较大，执行器仍受状态机、PID、温度反馈和硬约束保护。
