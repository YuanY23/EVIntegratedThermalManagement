# LSTM热负荷预测方法

## 预测任务

采样周期为5秒，使用过去300秒即60个时间步，预测未来300秒即60个时间步。输入包含车速、环境温度、电池温度、电机温度、座舱温度、电池功率、泵命令、时间，以及由在线物理估算器得到的历史电池产热、电驱余热和座舱净负荷。输出为三类热负荷的未来序列。历史热负荷只使用当前及过去值，不包含预测窗口内的未来标签，因此不构成数据泄漏。

## 数据生成与划分

训练数据来自整车物理仿真。工况覆盖城市、高速、激烈驾驶、坡道、高温、低温和温和混合工况，并扰动环境温度、初始部件温度、初始SOC、太阳辐射和车速尺度。训练、验证和测试按完整episode划分，窗口不能跨越episode边界，标准化器只拟合训练episode。

## 模型结构

编码器LSTM压缩历史动态，解码器从最后一个历史热负荷状态开始，将上下文和上一时刻三通道预测递推到未来60步。输出采用残差形式学习相对持久性基线的变化。训练采用AdamW、归一化MSE、梯度裁剪、逐步降低teacher forcing比例和验证集早停。保存最佳权重、输入/输出标准化器、训练历史和物理单位测试指标。

## 评价与安全

分别计算三类负荷的MAE和RMSE，不能只报告归一化损失。推理端检查输出形状、有限性和工程范围。历史不足前标记 `history_warmup`，异常输出标记错误原因，控制系统自动使用基准阈值。
