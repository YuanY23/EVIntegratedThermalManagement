# 旧版项目与历史结果归档

> 状态：**已弃用（superseded）**
>
> 归档日期：2026-08-09
>
> 当前项目入口：[`../../README.md`](../../README.md)

本目录保存项目升级前及升级过程中的旧叙事、旧运行索引和历史学习材料，仅用于追溯“项目是怎样演进的”。任何当前研究结论、简历数字、面试回答或后续 AI 分析都不得以本目录为主要依据。

## 1. 为什么归档

旧材料存在以下一种或多种问题：

- 只覆盖原始的物理模型、状态机、PID和LSTM预测，没有把参数辨识、一维液路、三架构比较、快充到站预热和联合优化纳入同一研究主线；
- 引用的是旧 plant SHA，对应代码已经被升级；
- 部分材料仍使用升级前的策略均值，例如电池峰值降低约0.280 °C、百公里电耗增加约0.0874 kWh/100km；最终正式运行的对应值已经变为0.312 °C和0.0970 kWh/100km；
- 旧报告把新增研究放在附录，不能准确代表当前项目的主体贡献；
- 旧 quick 运行只用于链路冒烟检查，不具备正式结论资格。

## 5. 使用规则

1. 默认不要读取本目录。
2. 只有在回答“旧版本为什么被替换”“某个历史数字来自哪里”时才读取。
3. 不得把历史运行与当前代码混合比较后形成新结论。
4. 不得从旧文档复制简历数字，当前数字必须回到机器可读结果核验。
5. 需要恢复历史运行时，应复制回新的临时目录，不要覆盖当前正式运行。
